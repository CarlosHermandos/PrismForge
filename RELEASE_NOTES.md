# PrismForge 0.3.1 — macOS Apple Silicon beta

AU, VST3 and standalone instrument with 112 original sounds plus Init.

This release replaces the top preset popup with a Browse button that opens the categorized PATCH browser. Click a named sound to load it. Preset rows expose their names to accessibility tools. Factory program numbers and saved-state schema are preserved.

The macOS ZIP includes the installer, binaries, concise instructions, licenses and full corresponding source in a nested archive. No separate preset download is needed. Quit Logic before installing. Previous PrismForge components are backed up.

Validated: preset selection in Logic changes the loaded name and controls; editor selection changes rendered audio in regression tests; all factory state round trips, native AU/VST3 integration and strict AU validation pass. This remains an ad-hoc-signed, non-notarized beta with documented DSP/QA limits.
