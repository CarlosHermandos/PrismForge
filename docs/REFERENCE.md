# Parameter, MIDI and file reference

## Parameters
`Content/Parameters.tsv` lists all 551 stable IDs, names, units, minimum/maximum/default, JUCE NormalisableRange skew and discrete interval. The first eight foundation IDs are unchanged. Host automation snapshots are taken at block boundaries, not advertised as sample-accurate automation. Continuous values use a 5 ms exponential target smoother. MIDI events and internally generated note events use sample timing. Oscillator phase/phase-random settings take effect at note start; portamento time is captured when a target note starts.

Normalized modulation sources: envelopes/velocity/note/controllers/macros 0..1; ordinary LFOs and random -1..1, optionally converted to unipolar. Sixteen routes store source, destination, signed amount, unipolar conversion, bypass and a power-curve shape. Destination spans are explicit: table/level/resonance/warp/sub/noise full 0..1 span; pan two pan units; pitch 24 semitones; cutoff ten octaves. Depth is applied before destination-specific bounds, independently of the knob's GUI skew. Sources cannot modulate route definitions or create circular oscillator dependencies. Eight-point LFO shapes interpolate linearly and wrap. One-shot LFOs use per-note clocks even when ordinary retrigger is off.

Attack/decay/release curves range from exponent .25 to 4. Attack rises from its current/initial level; decay reaches sustain in the selected decay time. Release specifies a full-scale fall time, so a lower current level releases proportionally sooner. Sustain changes interpolate over 3 ms. Envelope 1 is amplitude; 2-4 are routable. Monophonic legato retains envelope stages; retrigger restarts them. Portamento is a linear semitone ramp that reaches the target in the selected time.

Polyphony is 1..16. Overlapping identical keys release in FIFO order. Released voices are stolen first, then oldest active voices, with a 3 ms decaying residual. Fixed-seed preparation is reproducible; changing seed restarts future random decisions without reallocating the engine. Ordinary bend is ±2 semitones. Velocity scales amplitude, mod wheel adds wavetable position (or assigned filter motion in hybrid factory patches), pressure adds amplitude, and note-off velocity is available as a matrix source. Sustain is per channel; CC123 releases notes, CC120 clears voices and global effect tails. One-shot samples can finish before their amplitude release; looping takes precedence when explicitly enabled.

MPE uses channel 1 as master and channels 2-16 for note expression, with manually selected member bend range (default ±48). Per-channel pressure and CC74 are routable. Automatic RPN/MPE-zone negotiation, upper-zone operation and MIDI 2.0 are not implemented. Arp/sequencer output is internally flattened to channel 1.

## Sample, wavetable and spectral formats
- Wavetables: packed mono/stereo WAV/AIFF, 1..64 complete equal-sized frames; core reader accepts power-of-two frame sizes 32..8192, UI offers 256..4096. Stereo is averaged. Frames are resampled to 2048 points, DC removed, optionally normalized, then ten Fourier mip levels are generated. Export packs 2048-point frames into a mono 24-bit WAV at 44.1 kHz. WAV rate does not determine table pitch.
- Samples: decoded 8..192 kHz, 32 frames to eight seconds, stereo or duplicated mono. Nonfinite data and magnitudes above ±4 are rejected. Playback uses prepared low-pass decimation mip levels with cubic interpolation and crossfade between mip levels. Extreme playback ratios beyond prepared bandwidth are silenced. Loop lengths/crossfades are bounded; start/end positions are normalized. Reverse, gain, one-shot and loop controls are stored.
- SFZ: `<global>`, `<group>`, `<region>` with `sample`, `key`, `lokey`, `hikey`, `lovel`, `hivel`, `pitch_keycenter`, `tune`, `volume`, `loop_mode`, `loop_start`, `loop_end`. Numeric and C4=60 note names are accepted. Paths may be quoted and are relative to the SFZ. At most 128 regions and six million total stereo frames. Loops support no_loop/one_shot/loop_continuous; unsupported loop modes fail. Unsupported opcodes are explicitly reported and ignored. Missing sample paths are identified. This is not general SFZ compatibility.
- Granular: 64 fixed grains per voice/oscillator; Hann windows and overlap-weight normalization. Excess births are dropped when the pool is full. Movement traverses the source independently from note/grain pitch; position jitter and stereo spread are bounded. Changes of source reset the grain pool and crossfade the output.
- Spectral: imported audio is analyzed with a 2048-point Hann FFT and 512-point hops at its source rate. Energy near up to 32 harmonics of the selected analysis root is retained. Playback interpolates magnitude frames and resynthesizes harmonic sine partials at MIDI pitch, with time position, spectral tilt and harmonic count. Phase/in-harmonic/noise detail is not reconstructed; transients smear over the analysis window and may lose attack character. It is additive harmonic resynthesis, not sample playback. Preparation has no playback latency; analysis is off-thread. Factory spectral magnitudes are generated analytically from original harmonic recipes. Changing analysis root requires reimporting the file.

## State and presets
`.prism` is JUCE binary XML using `AudioProcessor::copyXmlToBinary`. Root `PrismForge schema="2" program="0..64"` holds all `PARAM id="..." value="..."` children, metadata (`presetName`, category, tags, author, description, macroName1..4), and up to three `ASSET` children with slot number and compressed payload. Schema 1 imports the original eight IDs and fills all new controls from defaults. Schema 2 requires every current parameter. Duplicate known IDs, invalid numbers/ranges/steps, malformed assets and unknown schema versions reject the entire input without resetting parameters. State input is limited to 64 MiB.

Asset payload PFAS/version 1 is little-endian typed data, gzip compressed and JUCE-base64 encoded. It embeds source frames/audio/zones/harmonic spectra; prepared mip tables are rebuilt outside processBlock. No external source path is needed after saving, so export is a portable single file. Decoded assets are bounded to 64 MiB. No asset is freed on the audio thread. User imports and exports retain the user's content; factory exports contain generated original assets.

User files and favourites are separate from the compiled factory bank, under the user's Music/Prism Forge/Presets folder. Factory rename is prevented; Duplicate/Save As creates a user file. Editor size/focus/scroll are not sound parameters and are not persisted. No commercial-synth preset importer is included.

## Effects and host reporting
Chain slots select each of eight serial processors; duplicate selections are skipped safely. Effects have 10 ms bypass transitions. The delay clamps feedback to .92 and delay time to two seconds; reverb is a stable four-line feedback network. EQ has low/high shelves and one adjustable-frequency peaking band. Saturation uses a two-sample interpolated nonlinear stage; this is not a fully specified oversampling filter or an alias-free claim. Filter drive, hard sync and other nonlinear warps also have quality limits. The optional limiter is a zero-lookahead sample-peak ceiling, not a mastering limiter or true-peak limiter. Default limiter is off. Reported fixed latency is zero and conservative tail time is 180 seconds.
