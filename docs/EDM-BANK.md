# EDM expansion bank

48 original patches, eight each in Brass, Bass, Leads, Pads, SFX and Chords. Appended at program indices 65–112; existing indices and sounds are preserved. Existing Lead/Pad categories are displayed as Leads/Pads.

Chords patches play fixed intervals from a single MIDI note and transpose chromatically; they do not follow a project key. Seventh shells omit the fifth. Hold riser notes for four to five seconds. All sounds retain four assigned macros: Brightness, Table morph, Resonance and Softness. Start with macros at zero.
